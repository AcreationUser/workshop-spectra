# Спектры — авторская мастерская (первая версия)

Локальное PWA-приложение для структурирования материалов цикла «Спектры».

## Что уже работает
- Шесть типов карточек: Вопрос, Мотив / нить, Концепт, Эмоция, Художка, Бэкграунд.
- Зрелость, приоритет, тома и привязка к эпизоду.
- Отметка ожидания с указанием карточки-зависимости.
- Связи между карточками с типом и пояснением.
- Поиск и фильтры по типу, тому и приоритету.
- Локальное хранение в IndexedDB.
- Экспорт и импорт JSON-резервной копии.
- Тёмная тема по умолчанию и светлая тема.
- Service worker для офлайн-работы после первого запуска.

## Запуск
PWA и service worker требуют localhost или HTTPS. Самый простой вариант — распаковать папку и запустить локальный статический сервер из неё:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере. Для установки на телефон открой меню браузера и выбери «Установить приложение» / «Добавить на главный экран» (название зависит от браузера).

Для установки на другом устройстве или постоянного доступа по HTTPS папку можно опубликовать на статическом хостинге. Данные при этом остаются в локальном хранилище браузера и автоматически между устройствами не синхронизируются.

## Важно о данных
Данные хранятся локально в браузере на конкретном устройстве. Регулярно используй кнопку экспорта (⇧) и храни JSON-файл резервной копии отдельно. Импорт заменяет текущую библиотеку.

## Ограничения прототипа
Это первая рабочая версия, не финальная архитектура. Сейчас связи хранятся в карточке-источнике, а не как полноценный двусторонний граф; удалённые карточки могут оставлять «осиротевшие» ссылки. Это можно улучшить на следующем этапе. Также пока нет совместного доступа, облачной синхронизации, вложений и прямой интеграции с твоим существующим трекером эпизодов.
